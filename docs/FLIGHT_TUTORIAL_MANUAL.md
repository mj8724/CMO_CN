# CMO 飞行教程通关手册与注意事项（汉化版）

> 适用：`Command: Modern Operations` v1.10 内部版本 1900.23 + 本汉化包。
> 场景目录：`Scenarios/Tutorials/Air Warfare Tutorials/Flight Tutorial/`。
> 本文是**实机操作手册**：每一关给出入口、按键、判定标准与踩坑点。
> 术语一律用游戏内实际显示的中文（括号内为原文），便于在界面上对照。

---

## 0. 三十秒上手

1. 主菜单 → **加载**（`TSMI_LoadScenario`）→ 展开 **飞行教程** → 选 `Flight Tutorial N - …` → **加载**。
2. 弹出 **阵营选择与简报** → **进入想定**；若出现 **想定特性与拟真度选项**，点 **开始推演**。
3. 教程会不断弹出 **专用战情消息** 窗口。它**会暂停推演**；读完点 **关闭并继续** 继续。
4. **空格** = 开始/暂停推演。绝大多数操作都要求推演处于**运行**状态，否则按钮是灰的。
5. 选中单位 → 用工具条/快捷键下命令；`ESC` 取消当前操作。

> ⚠️ 最容易踩的一条：**暂停时不能出动飞机、不能下新命令**。看到「单机起飞」灰着，先按空格。

- **机场/跑道没有挂载与燃油面板**——那是正常的，不是汉化缺失。只有**飞机/舰艇**才有「单元武器」「单元燃油」。

## 2. 飞行教程 1 —— 基础手动飞行（Basic Manual Flight）

**目标**：准备飞机 → 出动 → 手动飞行 → 返航着陆。

**步骤**
1. `SPACE` 开始推演。
2. 选中 **拉马特戴维**（Ramat David）机场 → `F6` 打开 **航空作业**。
   - 也可选中机场后点右栏 **编队状态** 面板上的「飞机」。
3. 在飞机列表里选一架 **就绪** 的 `F-16I「苏法」`（Sufa，挂 `AIM-120C-7 AMRAAM`）→ 底部 **单机起飞**。
   - 未就绪的机（`就绪所需时间` 显示 2 小时 57 分 / 5 小时 57 分）不能起飞。
4. 几分钟后状态由 `停机中` → `滑行准备起飞` → 升空。**升空后才可操控**。
5. 选中该机 → `F3` 规划航线：指针变箭头，点海图落点得第一段；继续点或 `ESC` 结束。
6. `F2` 改速度/高度（低空可躲雷达，高空可避 MANPADS）。
7. 打完/油尽会自动返航（Winchester / Bingo）；也可按 `B` 立即返航。

**判定**：≥1 架 F-16I 完成「起飞 → 按航线飞行 → 返航」。

**注意事项**
- 暂停时「单机起飞」是灰的 → `SPACE` 后再点。
- 航空作业窗口的表格是**树形**：第一行是机队组（`6x F-16I Falcon [Sufa]`），下面才是具体机号。
- 教程消息会打断推演（自动暂停），读完点 **关闭并继续** 才不会卡住。

## 3. 飞行教程 2 —— 无人干预飞行（Unattended Flight）

**目标**：用参考点 + 任务系统，让飞机自己飞。

**步骤**
1. 菜单 **任务与参考点 → 划定区域**，拖出一个 4 参考点矩形；问「是否创建区域实体」时选 **否**。
   - 或 `CTRL+右键 → 划定区域-矩形`。
2. 框选/逐个选中这些参考点（选中为亮白）。
3. `CTRL+F11`（或 任务与参考点 → 添加新任务）→ 命名 → 任务类型选 **巡逻** → 子类型 **防空巡逻** → 状态 **已激活 (Active)** → 确定。
4. 在任务编辑器里把 F-16I 编入该任务。
5. 再做 **支援** 任务：`任务与参考点 → 取消选择全部参考点`，再 `添加参考点` 放点，`CTRL+F11` → **支援** → 编入 2 架 G550「纳赫雄」预警机与 2 架 Hermes 900 无人机。
6. 再建一个 **支援** 任务给 2 架 707「萨克奈」加油机（延长滞空）。

**判定**：巡逻任务激活、飞机按任务自动巡逻；支援任务里有预警机/加油机。

**注意事项**
- 任务类型/子类型是**两级下拉**（第三个菜单 = 类型，第四个 = 子类型），别只选第一级。
- 支援任务不加参考点会建不出来。

## 4. 飞行教程 3 —— 简单空中拦截（Simple Air Intercept）

**目标**：拦截并击落一架 `「沙赫德」-129` 无人机。

**步骤**
1. 让战斗机升空（`F6` → 选机 → 单机起飞），或建防空巡逻任务。
2. 打开雷达发现目标：`CTRL+SHIFT+F9` → 雷达 **开机**（会暴露全部单位）；更稳的做法是选中某一部雷达 `F9` → 取消「单位遵守辐射控制」→ 勾选「雷达」。
3. 选中战斗机 → `SHIFT+F1` 手动交战 或 `F1` 自动交战 → 选目标 → 分配导弹。
4. 等导弹命中。

**判定**：无人机被击落。

**注意事项**
- **先识别再开火**：战区有民航，误击会失败。
- 老式红外弹（尾后攻击）要绕到目标尾后；全向弹可迎头打。

## 5. 飞行教程 4 —— 逼真探测与拦截（Realistic Detection & Intercept）

**目标**：探测并击落**会规避**的目标（Cessna AC-208B，随后 Il-38 / Tu-22）。

**步骤**
1. 开雷达（同上，推荐单部雷达开机）。
2. 发现接触 → 判明敌我 → 派 F-15/F-16 拦截。
3. `AIM-7「麻雀」III` 是**半主动雷达制导**：发射后必须保持机头指向目标且雷达开机，否则导弹失的。
   - 让 AI 自动攻击（`F1`）可免去手动保持。
4. 后续大型机（Il-38、Tu-22）抗伤高，优先用 `AIM-120 AMRAAM` 或 `AIM-7`。

**判定**：全部入侵目标被击落。

**注意事项**
- 半主动弹手动打极易脱靶；新手直接 `F1` 自动交战。
- 大型机多发动机，打掉一台还能飞，别以为一发就够。

## 6. 飞行教程 5 —— 复杂拦截（Challenged Intercept）

**目标**：击落挂**近程尾后弹**的 MiG-21，以及挂**中程弹**的 MiG-23。

**步骤**
1. 先开一部雷达，起飞 1 架 G550 预警机，再起飞战斗机。
2. 判明目标后分配：
   - MiG-21「鱼窝」：近程弹（`「怪蛇」3`、`AIM-9`）即可。
   - MiG-23「鞭挞者」（挂 `AA-7`，2–16nm）：用 `AIM-120` 或 `AIM-7`。
3. `AA-7` 是半主动：**逼它规避**（发射自己的导弹）就能让它脱锁自毁。
4. 想用近程弹打「鞭挞者」也可以，但必须关雷达 + 地形/云层隐蔽接近，风险高。

**判定**：两型敌机全部击落。

**注意事项**
- 别用近程弹正面挑战中程弹载机，会被先手击落。
- 预警机先上天能大幅提前发现。

## 7. 飞行教程 6 —— 现代空中拦截（Modern Air Intercept）

**目标**：对抗挂 `AA-7C`、`AA-6` 的 MiG-23ML / MiG-25P，注意**双机编队**。

**步骤**
1. 开雷达 + 预警机；判明目标。
2. 至少 **2 对 2** 投入（长机+僚机）。
3. `AA-6` 射程 4–30nm，别在它射程内直线接近；用 `AMRAAM` 远程先射，或侧向机动消耗。

**判定**：全部敌机击落。

**注意事项**
- 敌机成对出现，单机突入容易被夹击。
- 远程弹发射后仍要保持雷达照射（半主动弹）。

## 8. 飞行教程 7 —— 现代俄制与中国武器（Modern Russian & Chinese Weapons）

**目标**：用隐身机（J-20B、FC-31、PAK-FA）对抗 MiG-29M2 等现代机，理解**隐身**与**WRA**。

**步骤**
1. 先用 A-50U 预警机 + 地面雷达建立态势。
2. `CTRL+SHIFT+F9` 设置**阵营 WRA**（武器投射权限），避免乱开火/浪费远程弹。
3. 隐身机（J-20B / FC-31 / PAK-FA）靠前，非隐身机在后。
4. 对挂中远程弹的「支点」(MiG-29M2) 优先用超远程弹或隐身机近距解决。

**判定**：全部入侵敌机被击落。

**注意事项**
- 超远程弹打高机动目标命中率低，别指望一发必杀。
- WRA 设置错的典型症状：有弹不打 / 乱打民机。

## 9. 飞行教程 8 —— 高级作战（Advanced Combat）

**目标**：夜间、强干扰、有地空导弹协同的**体系作战**；F-22/F-35 隐身突防。

**步骤**
1. 建立态势：预警机 + 地面雷达 + 电子战。
2. 优先**打掉敌方预警机**（AEW），让叙军失去引导。
3. F-22A / F-35I 前出，利用隐身 + IRST 伏击；注意 `J-10B` 也有 IRST。
4. 与陆基 SAM 连协同：把敌机赶进 SAM 杀伤区。
5. 夜间目视探测距离短，依赖雷达/IRST 与数据链。

**判定**：全部敌机击落（教程终局）。

**注意事项**
- 夜间 + 干扰下，雷达开机时机就是生死线（开太久会被反辐射导弹盯上）。
- 隐身不是隐形：开雷达/开弹舱会暴露。

## 10. 常见问题（汉化相关）

| 现象 | 原因 | 处理 |
|---|---|---|
| 「单机起飞」是灰的 | 推演暂停 | `SPACE` 恢复推演 |
| 右栏没有「单元武器/单元燃油」 | 选中的是机场/跑道/设施 | 选中**飞机**或舰艇 |
| 机场飞机列表为空 | 选中的是跑道而非机场 | 选 **机场**（如「拉马特戴维」）再 `F6` |
| 面板文字中英交替闪 | 游戏每 0.2–0.3 秒重建面板文本，汉化层回写存在时间窗 | 见 §11；已修「快照回写截断」与「半译串钉死」，新元素英文窗口仍在收敛中 |
| 某行还是英文 | 该串未入词库 / 属专有名词 | 术语约定：型号代号保留原文（`AIM-120C-7`、`F-16I`），说明文字必须中文 |
| 读消息后推演不动 | 消息窗口会暂停推演 | 点 **关闭并继续** |

## 11. 汉化层已知行为（给测试/排障用）

- 汉化以「注入 + 回写」方式工作：游戏刷新文本 → 汉化层重新翻译。所以**文本会随游戏刷新而重译**，正常。
- 判断「真频闪」：选中一架**飞行中的飞机**，观察「单元武器/单元燃油」，若中英文在 1 秒内反复切换即为频闪；静态机场面板不能用来判断。
- 采集证据用引擎诊断通道：`WPF_DUMP`（读面板文本）、`WPF_TEXTLOG`（读回写日志）、`FLICKER_PROBE`/`FLICKER_RESULT`（8ms 采样值序列）。
- 判据（回归用例 `L-panel-flicker`）：同一节点在连续采样中**不得出现中英翻转**，且推演时间必须前进。
