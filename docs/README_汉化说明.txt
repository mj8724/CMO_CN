========================================================================
   《Command: Modern Operations (CMO / 现代行动：指挥)》专家级全汉化包 v1.0
========================================================================

【汉化架构与特性】
1. 零侵入免破壳设计（CLR AppDomainManager + 底层字符串缓存池劫持 + WinForms动态控件树巡检）
   - 不修改 Command.exe 原始二进制字节，彻底绕过 SmartAssembly 强名称签名校验与防篡改自杀逻辑。
   - 双层汉化引擎：
     * 第一层（底层内存池直注）：在游戏初始化时自动向 `AoIBWWlDJbaf7LijnA` 解密缓存字典预注入 3,112 条高频核心偏移词条。
     * 第二层（UI控件树实时汉化）：后台线程以线程安全方式（BeginInvoke）动态接管全部 WinForms 窗体、MenuStrip 菜单、ToolStrip 工具栏、TabControl 标签页、DataGridView 表格列头、ListView 与 TreeView 节点，内置 3,160 条精确军事UI词条与 238 条复合短语模板。
2. 专家级现代兵棋术语校对
   - 由现代海空兵棋术语专家规范翻译：涵盖战区任务规划（CAP/AEW/ASW/SEAD/DEAD）、条令与交战规则（ROE/EMCON/WRA）、传感器与武器挂载（主动/被动声呐、合成孔径雷达、数据链、挂载方案）、数据库查看器与想定编辑器全套界面。

【使用方法（支持单文件独立运行）】
方式一：图形界面一键安装 / 还原
  1. 双击运行 `CMO_Chinese_Setup.exe`（本程序已内嵌全部汉化引擎与字库资源，单 EXE 即可独立运行）。
  2. 程序会自动检索 Steam 默认路径下的 CMO 游戏目录；若未自动识别，请点击【浏览...】选择包含 `Command.exe` 的游戏根目录。
  3. 点击【一键安装汉化】即可完成部署；点击【还原英文原版】即可无损恢复原始配置。

方式二：静默命令行模式（适合批处理或整合包调用）
  - 安装汉化：`CMO_Chinese_Setup.exe /install "游戏目录路径"`
  - 卸载还原：`CMO_Chinese_Setup.exe /uninstall "游戏目录路径"`

【自定义与扩充词库】
  - 游戏目录下的 `CMOLocalizer.json` 为开放式 UTF-8 JSON 词库文件：
    * `offsets`: SmartAssembly 底层字符串池偏移 ID 映射
    * `exact`: 界面控件精确文本映射
    * `partial`: 动态状态栏与复合词组替换映射
  - 玩家可随时使用文本编辑器修改或追加词条，保存后重启游戏即可生效，无需重新编译。
