## v4.2.1 — 数据库全量补齐 + 挂载武器汉化 + 复合字段规则解析

## v4.2.0 — 适配游戏 Build 1900.23 + 界面与消息日志补全

> 适配游戏内部版本：**1900.23**（游戏标题里的 `Command: Modern Operations v1.10 - Build 1900.23`）。上一版 v4.1.8 适配的是 1900.20。

### 为什么必须升级
2026-10-17 20:46 Steam 把游戏更新到 Build 1900.23（BuildID 25673213→25865381，2971 个文件，两个 depot 清单号都变了）。
新版把游戏内部**混淆成员名整体重命名**：旧引擎按名字反射定位字符串池会**静默失败**，状态栏/HUD/标尺等
3500 余条显示层文本会退回英文（实测现象就是突然到处是英文）。本版按**结构特征**重新定位注入点，
每次失败都明确写日志（不再静默），并新增**构建号哨兵**：启动时比对游戏实际构建号与安装清单，
不一致就写告警——以后游戏再更新，日志里能一眼看到。

### 用户可见修复

- **条令 / 交战规则**窗口的下拉值补齐：`Inherited, Always Fire / Ignore / Bingo / 5% / 100%` →「继承自上级，始终开火 / 忽略 / 返航油量 (Bingo) / 5% / 100%」等。

- **编队燃料**：`AvGas (200k Liter Underground Tank)` →「航空汽油（200k 升 地下油罐）」。
- **消息日志**：终局报告（命中/脱靶）、新空中/水面/潜艇/地面/武器接触、平台已分类、目标消失、诱饵欺骗或失败、单位被摧毁、`New contact! Designated … [Sensors: …] at 264deg` 等整段英文 → 中文框架（武器与单位型号名保留原文）。
- **EMCON 页签**「告警ALERT：」标签改为「告警：」——原先词条里保留了英文 `ALERT`，标签比原文宽约 67%，尾部被右侧下拉框盖住（用户报的「字被挡住了」）。

### 工程加固
- 注入点定位：名字优先 + 结构特征兜底（静态 `List<string>` + `List<int>` + `byte[]`，缓冲取最长），所有失败分支必写日志。

- 词典构建新增硬阻断：编译进游戏的源码字面量（如 `, 'Aircraft', '`）不再进入偏移注入表。
- **版本双号**：本补丁版本与「适配的游戏内部版本」同时写入安装器、更新助手、发版说明与 README。


## v4.1.8 — 引擎性能与门禁加固

- **又一批界面英文清掉了**：推演选项的「频率」「虚影显示」「样式化/方向化样式」「在光标处显示」「选择…」、条令的交战警戒等级（蓝/黄/橙/红，其中「绿」与其它三色拉齐）、损伤等级「轻微/较严重」、四条「重置受影响单位/任务（继承上方 EMCON/WRA）」，以及两处动态文案（「每 N 秒」「武器：<单位>」）。
  扫描方法也升级了：现在会**逐个打开下拉框检查全部选项**（以前只看界面上显示的当前值，所以「打开下拉才看得到的英文」一直漏着）。

- **修掉两处“看起来像英文/叠字”的界面问题**（界面扫描收尾）：
  ① 推演选项的 `Tacview` 页签以前会叠成「三维态势联动（三维态势联动 (Tacview))」（词条非幂等，被二次翻译时又套一层），现在稳定显示「三维态势联动」；
  ② 「想定特性与设置」窗口里有 4 条特性一直是英文——`Allow instant loading for landing planner`、`Point To Point Unit Communication`、`Realistic Order Chain`、`Variable burnout speed on boost-coast weapons`。
  我们先怀疑是「列表要滚动到位才翻译」，实机查证后否决了：这个窗口 17 条特性同屏全部可见、根本不滚动，就是这 4 条**当时没进词典**；现已补齐（着陆规划器即时装载 / 点对点单位通信 / 真实指挥链 / 助推-滑翔武器的燃尽速度可变），复验 17/17 全中文。
  顺带把「推演选项」的 7 个页签（含每个下拉框的全部选项）都扫了一遍，没有发现其它英文。

- **条令/交战规则窗口下拉项不再中英混杂**：`Inherited, …` 那批选项值补齐了术语（现为「继承自上级，…」）。
  同时修掉一个我们自己引入的缺陷：防「写拉锯」的熔断机制被**误触发**——只要组合框被反复访问、哪怕一次都没写入，也会被永久静音（游戏日志里累计 269~311 次假熔断），这是下拉项大面积显示英文的元凶之一。
  现在只有真正与游戏来回改写（真拉锯）才会熔断。实机验证：该窗口 12/12 选项全中文、纯英文 0 条，熔断零新增。

- **补齐几处你一眼能看到的英文**：天气编辑器里的 `Calm`/`Hurricane`（现为「无风」「飓风」）与
  页签 `Level 0`（现为「层级 0」）、快捷键窗口的标题 `Own Units`（现为「己方单位」）、
  Lua 脚本控制台的按钮 `Insert`/`RUN`（现为「插入」「运行」）。这几条以前根本不在词典里，
  所以同一屏里其它标签是中文、它们却是英文。
  说明：快捷键窗口的正文是富文本（整窗的快捷键说明），修它会丢排版且会碰到刚加固的输入保护，
  本次**有意不动**，作为已知限制记录在台账 R27。
  新增实机用例 `L-ui-residuals` 会抽查多个窗口，保证「词典里有译文的界面文本不会还显示英文」。

- **修复一个可能泄露你 API 令牌的隐患**：工作区里曾留下一个 Python 字节码缓存文件
  （`scripts/__pycache__/translate_worker.cpython-312.pyc`），里面有**明文**的 `sk-` 网关令牌。
  它没被提交，却躺在 `.gitignore` 忽略的目录里，于是「只检查已入库文件」的密钥门禁根本看不到它——
  任何一次打包 / 压缩 / 共享整个工作目录，都可能把令牌带出去。现在：删除该文件，
  并把密钥门禁的扫描范围从「只看已入库文件」扩成**三层**（已入库 + 未入库 + 危险的忽略项：
  `__pycache__/*.pyc`、`.env*`、`*.pem/*.key/*.pfx`、`*.log` 等），跳过哪些文件、为什么跳过也必须打印出来。
  **⚠ 已经泄露出去的那枚令牌必须在服务商（网关）侧吊销并重新生成，本机无法代劳。**
- **修复「重建词典会静默回退已修好的工坊 / 战役标签」这个陷阱**：以前任何人重跑一次词典构建脚本，
  产出的词典就和仓库里那份不一样——① 工坊页签的译名被一道旧批次的非幂等值覆盖回去
  （R20 修好的「创意工坊 (创意工坊 (Steam Workshop))」叠译会复活）；② 「系列战役」窗口的长标签
  被误当成脚本内容丢掉；③ Steam Workshop 页签所在的字符串池条目（偏移 7916）被过滤静默跳过；
  ④ 整个文件从 LF 被改写成 CRLF，凭空多出 4.9 万行换行差异。现在重建与已提交词典**字节完全一致**，
  不会再静默回退任何已修好的显示串。
- **页面翻译不再卡顿**：内嵌浏览器（想定简报 / 数据库详情）翻页时，引擎要拿整本 4.6 万条词典
  去扫整页文字，页面越大越慢——实测同一个页面要 0.67 秒，100KB 的页面要 2.08 秒（页面一大会像卡死）。
  现在加了页面级预筛（只有确实出现在页面里的词条才会被逐个尝试）：同一个页面 **0.67s → 0.135s**，
  100KB 页面 **2.08s → 0.39s**（约 5 倍），**翻译内容与之前逐字节完全相同**。
- **安装器不再能被构造的压缩包写到游戏目录之外**：安装器解压菜单图 / 想定 HTML 时没有校验压缩包里的
  条目路径，一个精心构造的压缩包可以用 `..\..\` 或绝对路径把文件写到游戏目录外面——而安装器是
  **管理员权限**运行的（`.orig` 备份还会再生成第二个越界文件，失败也不留任何日志）。现在每个条目
  落盘前都必须通过「路径必须留在目标目录内」的校验，越界条目被拒绝并在日志里写明；
  真实安装实测不受影响（`Symbols\Menu` 下 237 个文件正常落地，无一误拦）。
- **门禁不再会「空转假绿」**：两条硬门禁其实一直是坏的——① 简报翻译门禁在找不到任何目标文件时判定是
  `0 >= 0`，永远通过（现在目标为空直接判 FAIL）；② 历史密钥扫描用的 `git log -G` 写法受 git 自己的
  正则方言限制，对「确实存在过凭据改动」的仓库**一次都命中不了**（现在改为按内容对象去重后逐个扫描，
  实测扫描 560 个对象 / 79MB，覆盖率与跳过原因全部打印出来）。门禁现在都能被证伪，不再是摆设。

> 说明：本节已完成入库改动与 R29 界面修复的收尾；五处版本号（`VERSION`、安装器常量、安装器窗口标题、助手常量、
> 词典 `_meta.version`）已在本轮打包候选时统一提升为 **4.1.8**（尚未发布）。

## v4.1.7 — 输入闪退修复 / 战役内剧本名补齐 / 发版入库检查

- **修复「创建任务、搜索剧本时输入一个字符就闪退」**（用户实测：任务名框、搜索想定框输入 m 即闪退）：

  只有堆栈含本引擎时才吞掉异常——不会再把我们的缺陷变成你的闪退。
- **修复「战役里有些剧本名仍是英文」**：战役定义（`*.campaign`）里的剧本名有 25 条从未入词典

## v4.1.6 — 安装状态/设置/回退修复（内部版本，未发布，已被 v4.1.7 取代）

- **修复「还原后仍显示已安装新版本、想回退回退不了」**：以前「装了什么版本」只存在注册表里一个字符串，
  任何安装包一装就把它改成**那个包自己的**版本号，与真实部署的文件无关；更新助手又只看「最新版」，
  于是既不会反映真实状态，也永远不会提供回退。现在改为以游戏目录内的**安装清单**
  （`CMOChinese_Installed.json`：版本 + 安装时间 + 来源 + 引擎文件 sha256）为准：
  还原后立即显示「原版英文环境（未安装汉化补丁）」；装哪个包就显示哪个包的版本与时间；
  文件被人为改动时会提示「检测到 …与安装清单不一致，建议重新安装」。
- **新增：回退到上一版本**。安装/升级时会把安装包缓存到本机，安装器上的
  「回退到上一版本 vX」按钮或更新助手托盘菜单的「回退到上一版本…」可以离线回退；
  命令行：`CMO_Chinese_Setup.exe --rollback "<游戏目录>" --silent`，
  `--list-versions` 可查看已装版本与本地缓存版本。回退以**整个安装包**为单位，避免出现
  「旧引擎 + 新简报/按钮图/地名集」的混合安装；回退后引擎哈希必须与缓存包内嵌的一致才登记状态。
- **修复「还原后更新频率/托盘提醒等设置全没了」**：设置与安装信息原先挤在同一个注册表键里，
  还原会把整个键删掉。现在设置存在 `%APPDATA%\CMOChinese\settings.json`（旧注册表值会自动迁移），
  还原/卸载**不会**再动它；确实想一并清掉，请勾选安装器上新增的
  「还原时同时清除我的全部设置」（或 `--uninstall ... --purge-settings`）。
- **新增：安装器窗口内就能改更新设置**：直接选「自动检查频率」（每次开机 / 1 / 3 / 6 / 12 / 24 小时）
  与「提醒方式」（弹窗 / 仅托盘气泡 / 不提醒），不再只有一行写着「每 6 小时」的说明文字；
  更新助手设置窗新增「关闭更新窗口时最小化到托盘（后台继续）」。
- **存量用户与绿色包**：首次打开安装器或更新助手时会**自动登记**当前安装状态（读实际文件写清单），

   正是此前 `DAL KeyNotFoundException` 与 Lua 沙箱崩溃的失效模式。
