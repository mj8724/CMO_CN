# 全量地名复核的资料和授权

2026-10-19 对上游 `979c1d3` 的原始4,287个城市点和321个区域点开展复核。保留 PR #3 已有318条坐标审核记录；新审核记录按区域保存于 `dict/placenames_reviewed/global_*.json`，区域标签另存 `dict/placenames_synoptic_reviewed/global.json`。

## 集中资料

- [GeoNames](https://www.geonames.org/) 的 [daily dump](https://download.geonames.org/export/dump/) 和带语言标记的 `alternateNamesV2`。数据使用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)；本项目依据其英文名称、别名、坐标和中文异名进行选择、字形整理和人工纠正，修改后名称不代表 GeoNames 审定。字段定义见 [提供方 readme](https://download.geonames.org/export/dump/readme.txt)。每条记录的 GeoNames 链接保留实体编号，可定位数据来源。
- [Wikidata](https://www.wikidata.org/) 的结构化标签使用 [CC0](https://www.wikidata.org/wiki/Wikidata:Licensing)。以 GeoNames P1566、已有跨站链接或明确同名/坐标交叉核对，不能仅因两个资料存在链接便认为实体相同。记录保留对应 Q 编号链接。
- 国家/地区中文主要核对[外交部领事服务网目的地名单](https://cs.mfa.gov.cn/ljmdd/yz_645708/)及逐国材料；该页实际含全部洲的目的地导航。海域主要参考[联合国《第二次世界海洋评估》第一卷中文](https://digitallibrary.un.org/record/3978757/files/2011859CWOAIIVolIWEB.pdf)及各条记录列出的专业资料。未机械照搬其中个别异写。
- 具体疑难使用当地政府、外交机构、联合国、大学论文、旅游机构、当地华文媒体等逐条核对。引用链接及证据边界写入各条 `source` / `note`，不把整个国家介绍冒充每座城市名称的直接中文证据。

## 复核方法和边界

先用原文或明确别名与坐标建立候选，超过10公里、多个同名点、历史名称、街区和行政范围差异另行核查。此步骤只建立候选，不自动产生已审核中文。之后逐项阅读和裁决现成中文：排除车站、遗址、公园或外层行政区；保留原文历史名及居民点层级；已有华语地名优先，避免按拉丁字母逐字替换。

`source_type` 区分资料直接给出的中文与 `editorial` 人工编辑译写。后者可能只由来源确认实体，再人工按原语专名、惯用人名或“新/旧/村/港/区”等通名整理中文；记录明确说明没有现成中文直接证据，不冒称政府整名审定。繁简转换只整理字形，不能替代地名审校。

原始点位或来源跨链存在冲突时，保留原始坐标和原文所指对象，在 note 或 `identity_status` 中记载。例如印尼 Batang 的资料跨链相差118公里；不会把它自动换成较知名的同名市，也不会在地图标签中加入调试标记。

这些复核记录是可继续订正的编辑成果。完整覆盖门禁证明每个发行标签都有唯一审核记录、资产符合核准名称；程序无法自动证明每个中文译名都是国家标准。现成社区资料及人工译写的证据等级应与政府直接用名区分。

原始下载和完整候选缓存留在本次研究工作目录，不打包进补丁。仓库只保存必要的核准记录、来源编号、裁决说明及最终资产，后续修订直接针对坐标记录进行。
